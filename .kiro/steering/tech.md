# Tech stack and commands

## Stack

- Node.js 24 (`.nvmrc`), pnpm 10 (`packageManager` in `package.json`; `corepack enable`). pnpm only installs
  releases older than three days (`minimumReleaseAge` in `pnpm-workspace.yaml`).
- Vite 8 single-page app, base path `/orcasonar/`, output in `build/`. React 19, TypeScript 6 (strict,
  `noUncheckedIndexedAccess`, `verbatimModuleSyntax`, `erasableSyntaxOnly`: no enums or parameter properties).
- Routing: React Router 8 (`createBrowserRouter`, `basename` from `import.meta.env.BASE_URL`), pages lazy-loaded.
- Data: TanStack Query 5 for server state; TanStack Table 9 with ReUI's data grid for tables.
- API: `openapi-fetch` typed by `src/api/schema.d.ts`, generated by `openapi-typescript` from OrcaSonar's contract.
  Chat streams server-sent events, parsed with `eventsource-parser`.
- Auth: AWS Amplify 6 against the portal's Cognito pool; the ID token goes as `Authorization: Bearer`.
- UI: Tailwind CSS 4, shadcn/ui (Base UI, `base-nova` style), ReUI registry, lucide-react icons, sonner toasts,
  Inter at 13px. Theme tokens are CSS variables in `src/styles/index.css`.
- Markdown: react-markdown + remark-gfm + the console's `remarkCiteRefs`.
- Tests: Vitest 5 with jsdom and Testing Library.

## Commands

| Command            | What it does                                                         |
| ------------------ | -------------------------------------------------------------------- |
| `make install`     | `pnpm install --frozen-lockfile`, and pre-commit hooks if installed  |
| `make check`       | Types, lint, formatting and tests (`pnpm check`), as CI runs them    |
| `pnpm test`        | `vitest run` once; never use `pnpm test:watch` from an agent         |
| `pnpm lint`        | ESLint with type-checked rules                                       |
| `pnpm format`      | Prettier write; `pnpm format:check` to verify                        |
| `make build`       | `tsc -b && vite build` into `build/`                                 |
| `make api-types`   | Regenerate `src/api/schema.d.ts` from OrcaSonar dev's OpenAPI        |
| `make start`       | Dev server on :3000 against OrcaSonar dev (needs `aws sso login`)    |
| `make start-local` | Dev server on :3000 against `make local-api` (in-memory, no sign-in) |

`make start`, `make start-local` and `make local-api` are long-running: ask the user to run them in their own
terminal. CI (`.github/workflows/pr-tests.yml`) runs `pnpm check` then `pnpm build`; run `make check` before calling
work done.

## API types

- Never hand-edit `src/api/schema.d.ts`. Regenerate it with `make api-types` (`ORCASONAR_OPENAPI` can point at
  `../orcasonar/app/schema/openapi.yaml` for unreleased changes) and commit the result.
- Re-export schema types with friendly names from `src/api/types.ts` rather than reaching into `components['schemas']`
  elsewhere.

## Formatting and lint

- Prettier: 100 columns, single quotes in TS and JSX, semicolons, trailing commas `es5`, LF, Tailwind class sorting
  (`cn` and `cva` too). Don't fight it; run `pnpm format`.
- ESLint ignores `src/components/ui`, `src/components/reui`, `src/hooks/use-mobile.ts` and the schema. Unused
  variables are allowed only with a leading `_`. Fire-and-forget promises in handlers are written
  `onClick={() => void save()}`.
- Pre-commit blocks commits to `main`, and runs detect-secrets against `.secrets.baseline`. Never commit secrets or
  Cognito IDs; deployed settings come from `env.js` at run time.
